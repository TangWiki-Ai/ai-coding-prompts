# AI Coding Prompts

这是一套给 AI Coding 笔试用的提示词模板。中文名可以叫：AI Coding 笔试速通提示词。

它适合这些场景：

- 笔试题给你一个 README 或业务需求
- 题目给你一个已有工程，让你补功能或修问题
- 你需要和 AI 一起读代码、写代码、跑测试、根据反馈修复
- 你不想让 AI 一路自由发挥，而是想按步骤推进

## 有什么用

这套流程把 AI Coding 拆成 6 步：

1. 需求对齐：先读 README、项目目录、测试和核心代码，别急着写。
2. 架构设计：整理一份可执行的开发 spec。
3. 拆分开发：把 spec 拆成小 ticket，一次只做一个。
4. Code Review：对照 ticket 和 spec 检查有没有漏做、做偏或引入 bug。
5. 验收测试：对照 README 和 spec 看需求是不是真的完成。
6. 定点修复：根据测试反馈定位根因，只做小范围修改。

## 怎么用

打开 [prompts.md](./prompts.md)，按顺序复制对应阶段的提示词。

建议不要一开始就让 AI 写代码。先用第 1 步对齐需求，再用第 2 步形成 spec。后面每次只处理一个 ticket，这样更稳。

## 适合谁

- 产品、开发、算法岗位准备 AI Coding 笔试的人
- 对工程项目不熟，但需要快速拿到基本完成度的人
- 想让 AI 更像协作者，而不是随机生成代码的人

模板只能帮你稳定流程。想冲高分，你还需要结合题目要求，理解代码结构、业务规则和隐藏边界。
